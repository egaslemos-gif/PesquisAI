# SS-002: Checklist Authoring Standard

## 1. Objetivo das Checklists
A checklist não é um mecanismo burocrático de controlo. É um instrumento de **reflexão estruturada e garantia de qualidade (QA)** metodológica para o investigador antes de avançar para a etapa seguinte de um protocolo.

## 2. Quantos Critérios são Recomendados?
- O número ideal de itens por checklist situa-se entre **3 a 5 critérios**.
- Checklists com menos de 3 itens geralmente indicam que a etapa é demasiado simples (e deveria ser fundida com outra).
- Checklists com mais de 5 itens induzem fadiga cognitiva no investigador. Se uma etapa exige 8 itens de validação, a etapa está sobrecarregada e precisa de ser desdobrada.

## 3. Classificação dos Critérios
Para garantir abrangência, as checklists devem misturar dois tipos de critérios:

### 3.1. Critérios Objetivos (Validação Técnica)
Critérios de resposta binária, verificáveis de forma incontestável na mecânica da escrita.
- **Exemplo:** "A pergunta de investigação termina com ponto de interrogação."
- **Quando usar:** Para garantir que construtos obrigatórios estão presentes ou regras de formatação (e.g. normas APA) foram cumpridas.

### 3.2. Critérios Reflexivos (Validação Científica)
Critérios subjetivos que exigem que o investigador reavalie a qualidade epistemológica do que produziu.
- **Exemplo:** "A pergunta é exequível no prazo de 6 meses e com os recursos disponíveis?"
- **Quando usar:** Para avaliar validade, coerência e viabilidade metodológica.

## 4. Como Escrever uma Boa Checklist Metodológica
- Redigir como uma **afirmação na primeira pessoa do singular** (perspetiva do investigador) ou como uma **pergunta direta**.
  - *Afirmação:* "Defini claramente o período temporal da minha pesquisa."
  - *Pergunta:* "A minha questão de investigação menciona a população-alvo?"
- O texto deve ser acionável. Se o investigador responder "Não", o critério deve ser óbvio o suficiente para ele saber o que alterar.

## 5. O que NUNCA deve aparecer
- **Critérios vagos/subjetivos absolutos:** "A pergunta é boa?" (O que é "boa"?).
- **Múltiplos requisitos no mesmo item (Dupla condicional):** "O objetivo geral começa com um verbo no infinitivo E reflete as subcategorias analisadas?" (Separar em dois itens).
- **Critérios fora do escopo da etapa:** Pedir para verificar referências bibliográficas na etapa de "Definição do Problema" se estas ainda não foram recolhidas.
