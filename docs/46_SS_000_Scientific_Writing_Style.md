# SS-000: Scientific Writing Style Guide

## 1. Objetivo
Este documento define o guia de estilo para toda a redação de conteúdo científico e metodológico presente no Guia do Investigador. O objetivo é garantir uma voz unificada, rigorosa e pedagógica em todos os protocolos, *prompts* e bases de conhecimento.

## 2. Tom da Escrita
O tom do Guia deve ser **orientador, académico e direto**.
- **Orientador:** Assume o papel de um mentor experiente. Não faz o trabalho pelo investigador, mas mostra o caminho.
- **Académico:** Mantém o rigor terminológico (e.g., usar "epistemológico", "revisão sistemática", "hipótese", "construto").
- **Direto:** Evita jargão desnecessário que não acrescente valor metodológico. Vai direto ao ponto.

## 3. Pessoa Verbal
A comunicação deve ser feita na **terceira pessoa do singular** (direcionada ao utilizador) com um tom de formalidade intermédia, ou utilizando o modo imperativo para instruções claras.
- **Correto:** "Defina a sua questão de investigação", "O investigador deve garantir que..."
- **Incorreto:** "Nós achamos que deves...", "Eu vou ajudar-te a..."
- Nunca utilizar a IA na primeira pessoa. A IA não é uma entidade, é uma ferramenta.

## 4. Vocabulário
- Utilizar terminologia científica padrão (APA, normas académicas europeias).
- Evitar regionalismos ou expressões coloquiais.
- Promover a precisão: distinguir claramente "tema" de "problema", "objetivo geral" de "objetivos específicos".

## 5. Tamanho dos Parágrafos
Para garantir a máxima legibilidade (scannability) num ambiente digital focado em produtividade:
- Máximo de **3 a 4 linhas** por parágrafo.
- Uma ideia central por parágrafo.
- Evitar blocos densos de texto (paredes de texto). Se a explicação for longa, dividi-la em subtópicos.

## 6. Utilização de Listas
As listas (bullet points) são o formato preferencial para explicar processos, requisitos ou características.
- Usar listas numeradas para **passos sequenciais**.
- Usar marcadores (bullets) para **itens sem ordem hierárquica**.
- Os itens de uma lista devem ser sintaticamente paralelos (começar pela mesma classe de palavra, idealmente um verbo no infinitivo ou substantivo).

## 7. Utilização de Exemplos
Os exemplos são obrigatórios na explicação de conceitos metodológicos.
- Um bom exemplo deve ser claro, plausível e ancorado numa disciplina real (ex: Enfermagem, Educação).
- Apresentar contraste sempre que possível: mostrar um **Bom Exemplo (Correto)** seguido de um **Mau Exemplo (Incorreto)**.

## 8. Utilização de Citações
- Ao referir metodologias consagradas (e.g., PRISMA para revisões sistemáticas), citar o modelo formal e fornecer hiperligação para a fonte primária se aplicável.
- As citações não devem interromper o fluxo cognitivo; devem figurar em seções como "Leituras Recomendadas" ou "Fundamentação".
