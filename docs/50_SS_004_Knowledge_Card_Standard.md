# SS-004: Knowledge Card Standard

## 1. O que é uma Knowledge Card (Ficha de Base de Conhecimento)?
A *Knowledge Card* é a interface pedagógica que será acoplada a cada etapa de um protocolo (e.g. painel lateral "Saiba Mais" ou "Assistente Científico"). Ela transporta a fundamentação metodológica (definida no RFC-S-018) para a frente do utilizador, sem o retirar do contexto de escrita do seu artefacto.

## 2. Como é uma boa ficha?
Uma boa ficha é modular, escaneável e imediatamente aplicável ao problema em mãos. Não deve ser um tratado teórico, mas sim um apoio à decisão científica. 

## 3. Estrutura Obrigatória da Ficha
Toda a ficha técnica agregada a uma etapa deverá, inevitavelmente, cobrir os seguintes tópicos estruturais:

### 3.1. Título e Objetivo
- **Título:** Claro e focado na tarefa da Etapa (e.g. "Como Formular a Pergunta de Investigação").
- **Objetivo (1 linha):** O que se pretende atingir. "Estabelecer o fio condutor de toda a sua pesquisa."

### 3.2. Conceito / Explicação
- Explicar, usando no máximo 2 parágrafos de 3 linhas, qual o enquadramento teórico da tarefa.
- Exemplo: "A questão de partida é a pergunta nuclear à qual a pesquisa tentará responder. Ela não pode ser respondida com Sim ou Não, devendo indagar sobre o 'como' ou o 'porquê'."

### 3.3. Exemplos Reais (Contraste)
O contraste pedagógico (Certo vs Errado) é o modelo mental mais rápido para correção autónoma.
- **Bom Exemplo (✔):** "Como é que a introdução do sistema de triagem de Manchester alterou o tempo de espera no Serviço de Urgência X no ano de 2024?"
- **Mau Exemplo (✖):** "O sistema de triagem é bom para os hospitais?" (Vago, avaliativo e binário).

### 3.4. Erro Frequente (Gotchas)
O ponto de maior atrito em cada fase, documentado para prevenir falhas antes destas passarem pelo *Review Engine*.
- Exemplo: "Um erro comum é confundir a pergunta de investigação com uma pergunta de questionário/entrevista a ser feita aos participantes da amostra."

### 3.5. Leitura Recomendada e Ferramentas
Hiperligações ou referências para aprofundar o tema, bem como recomendações sobre as ferramentas de software de auxílio adequadas.
- **Ferramentas:** Zotero (Gestão de Referências), Elicit (Mapeamento Inicial).
- **Leitura:** Bibliografia seminal sobre metodologia científica aplicada àquela área.

## 4. O Impacto na UX
Esta estrutura de conteúdo será o mapa base para desenharmos a futura Interface de Utilizador (UI). É este conteúdo que ditará se precisaremos de "Accordions", "Side-drawers" ou "Modais" para a fase Nível 3 da PHASE II.
