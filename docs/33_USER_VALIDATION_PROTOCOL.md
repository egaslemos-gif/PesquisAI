# 33 — User Validation Protocol (Phase 3)

Este documento define o protocolo oficial para a avaliação da usabilidade e do valor metodológico do Guia do Investigador. O objetivo desta fase é validar a experiência real de utilização, não apenas a corretude do código.

A Fase 3 divide-se em três níveis de validação:

## 3.1 Functional Validation
**Objetivo:** Confirmar que tudo funciona no browser real sem falhas.

- [ ] Criar investigação
- [ ] Editar etapas
- [ ] Copiar prompts
- [ ] Reiniciar investigação
- [ ] Recarregar página
- [ ] Persistência de dados
- **Resultado Esperado:** O sistema funciona de forma fluida e sem erros impeditivos (Zero Bugs).

## 3.2 Usability Validation
**Objetivo:** Avaliar se o investigador compreende naturalmente a interface.
**Pergunta Central:** "O investigador sabe o que deve fazer a seguir sem ajuda externa?"

- [ ] Conseguiu iniciar a investigação sem ajuda?
- [ ] Compreendeu a diferença entre "Guardar" e "Concluir"?
- [ ] Percebeu porque os artefactos foram invalidados (feedback de retrocesso)?
- [ ] Encontrou facilmente a próxima ação?
- [ ] Houve momentos de hesitação prolongada?

## 3.3 Methodological Validation
**Objetivo:** Avaliar a qualidade científica e académica do protocolo.
**Pergunta Central:** "O protocolo conduz a decisões metodologicamente corretas e produz trabalho de qualidade?"

- [ ] O protocolo orienta para decisões metodologicamente corretas?
- [ ] Os prompts são suficientemente claros e específicos?
- [ ] Os artefactos produzidos pelas IAs externas têm qualidade académica?
- [ ] O fluxo segue uma lógica académica natural?
- [ ] Existem etapas redundantes?
- [ ] Existe alguma lacuna metodológica?

*(Nota: O avaliador ideal para este nível deve ser um docente, orientador ou investigador experiente.)*
