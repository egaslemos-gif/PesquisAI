# 35. Protocolo de Internal Beta

**Objetivo:**  
Validar o Guia do Investigador com utilizadores reais e observar o comportamento humano na utilização da plataforma, recolhendo dados que orientarão a RC2.

## Participantes
- Docentes
- Mestrandos
- Investigadores

## Tarefas

Cada participante deverá, num período de cerca de cinco minutos:
1. Iniciar uma investigação.
2. Concluir um protocolo.
3. Utilizar pelo menos um prompt.
4. Utilizar uma ferramenta.
5. Preencher um artefacto.
6. Concluir uma checklist.

## Questões de Feedback

Após a conclusão das tarefas, o participante deverá responder de forma direta:

1. Conseguiu concluir o protocolo?  
   **[ ] SIM / [ ] NÃO**

2. Em que etapa teve mais dúvidas?  
   _________________________________________________________

3. Utilizou os blocos de ajuda (💡 Antes de começar)?  
   **[ ] SIM / [ ] NÃO**

4. Os prompts foram úteis?  
   **[ ] SIM / [ ] NÃO**

5. Voltaria a utilizar a plataforma?  
   **[ ] SIM / [ ] NÃO**
