# 09 - Artifact Model

É o documento mais importante depois da Constituição. Define que cada etapa finalizada se traduz num entregável concreto e registado. 
No final do workflow teremos uma coleção estruturada de artefactos.

## Relação Etapa-Artefacto

**Tema**
↓
Artefacto

**Pergunta**
↓
Artefacto

**Objetivos**
↓
Artefacto

*(O processo repete-se para cada etapa. O output consolidado de cada passo forma a documentação/artigo final.)*
